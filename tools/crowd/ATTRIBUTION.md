# Studio-audience recordings

The crowd reactions in `public/audio/` are cut from freely-licensed recordings
of real audiences. `tools/crowd/fetch.sh` downloads the sources and
`tools/crowd/build.py` cuts the clips, so the whole set is reproducible.

| Clip | Source | Author | Licence |
| --- | --- | --- | --- |
| `cheer.m4a` | [Clapping hurray](https://commons.wikimedia.org/wiki/File:Clapping_hurray.ogg) | Wikimedia Commons | Public domain |
| `applause.m4a` | [applause-2](https://commons.wikimedia.org/wiki/File:277021_sandermotions_applause-2.wav) | sandermotions | CC0 |
| `applause-big.m4a` | [approx 800 laughter and clapter](https://commons.wikimedia.org/wiki/File:72844_lonemonk_approx-800-laughter-and-clapter-1.wav) | lonemonk | **CC BY 3.0** |
| `groan.m4a` | [Audience Booing](https://commons.wikimedia.org/wiki/File:Soundgoats_-_Audience_Booing.wav) | Soundgoats | Public domain |

`applause-big.m4a` is the only clip that carries an attribution requirement.
Crediting "lonemonk" (CC BY 3.0) somewhere user-visible — an About screen or
the page footer — satisfies it. Everything else is CC0 or public domain and
needs no credit.
